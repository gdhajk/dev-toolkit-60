# dev-toolkit-60: Autoclicker

dev-toolkit-60 is a powerful Python-based autoclicker designed to automate mouse clicks efficiently and seamlessly. Ideal for tasks requiring repeated clicking, this tool can help streamline workflows and save time on repetitive tasks.

## Features
- **Customizable Click Intervals**: Set precise durations between clicks, allowing total control over interaction speed.
- **Hotkey Support**: Start and stop clicking with customizable keyboard shortcuts for quick and easy access.
- **Cross-Platform Compatibility**: Works on Windows, macOS, and Linux, ensuring a wide range of users can benefit from its capabilities.
- **Simple User Interface**: Comes with an intuitive command-line interface that makes setup and usage straightforward for users of all skill levels.

## Installation

To install the autoclicker, clone the repository and install the required dependencies:

```bash
git clone https://github.com/Developer/dev-toolkit-60.git
cd dev-toolkit-60
pip install -r requirements.txt
```

## Basic Usage Example

Once you've installed the autoclicker, you can start it easily using the command line. 

```bash
python autoclicker.py --interval 0.1 --hotkey 'F8'
```

In this example, the autoclicker will click every 0.1 seconds and start/stop with the F8 key. Modify the `--interval` parameter as needed to suit your clicking speed.
